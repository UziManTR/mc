# MC PvP
Browser-based Minecraft-style PvP arena.

## Current systems
- Three.js voxel arena
- WASD + sprint
- Sword / mace / spear
- Animated hotbar and attacks
- Health and target bars
- Toggleable hitboxes
- Procedural pixel-style block textures
- NPC combat bot
- Supabase Realtime multiplayer architecture
- Responsive HUD

## Controls
WASD move, Shift sprint, mouse aim, left click attack, right click block, 1/2/3 weapon, F3 hitbox overlay, Esc menu.

Supabase uses only a publishable/anon key in the browser. Never put a service_role key in config.js.
